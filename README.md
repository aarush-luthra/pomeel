# Dark Patterns in Indian D2C E-commerce

Two parts, presented together:

| Part | Folder | What it is |
|---|---|---|
| 1. Detection pipeline + findings report | `scraper/` | Scrapes a small real sample, flags candidate dark patterns, classifies them, writes `scraper/report/report.html` |
| 2. Teaching page | `teaching_page/index.html` | Static, interactive "manipulative vs honest" examples with invented stores. Collects nothing; the scraper never touches it. |

## Pipeline

```
collect.py  ->  extract.py  ->  store.py  ->  classify.py  ->  report.py
Playwright      BeautifulSoup    ChromaDB      GPT-4o-mini or     tables, figures,
HTML+screenshot rules + crops    embeddings    keyword baseline   evidence, limits
```

### Run

```bash
cd scraper
python3 run.py all                      # full pilot: ~15-20 min for 12 sites
```

Individual stages:

```bash
python3 run.py collect --site Plum      # one site (repeat --site for more); --headed to watch
python3 run.py extract
python3 run.py store
python3 run.py classify                 # Nebius if NEBIUS_API_KEY is set, otherwise keywords
python3 run.py validate-sample          # writes data/validation_sample.csv (30 rows)
python3 run.py report
python3 run.py query "only a few items left"   # semantic search over stored candidates
```

### Classifier backend

Copy `.env.example` to `.env.local` (git-ignored) and fill it in:

```
NEBIUS_API_KEY=...
NEBIUS_MODEL=meta-llama/Meta-Llama-3.1-70B-Instruct
```

* `NEBIUS_API_KEY` set → Nebius AI Studio (OpenAI-compatible API) with the CCPA 2023 + OECD definitions in the
  prompt, JSON output (`is_dark_pattern`, `pattern_type`, `confidence`, `reason`). Force with `--backend nebius`.
* `OPENAI_API_KEY` set instead → GPT-4o-mini (`--backend openai`).
* No key → transparent keyword/rule baseline (`--backend keyword`), so everything still runs.
* Confidence below 0.7 (`config.CONFIDENCE_THRESHOLD`) → "needs review", excluded from headline numbers.

### Validation (Table 2)

1. `python3 run.py validate-sample`
2. Open `scraper/data/validation_sample.csv`; for each row look at `crop_path` and fill `human_is_dark` with 1 or 0
   (optionally `human_pattern_type`).
3. `python3 run.py report`: Table 2 now shows precision, recall within the sample and accuracy.

### Countdown consistency check

Every countdown is turned into an implied end time (snapshot time + remaining time). If the end times for the
same site disagree across page loads by more than 5 minutes, the timer isn't tied to a real deadline. This costs no
extra requests.

### Ethics

Public pages only, no logins, no personal data, no orders. robots.txt is checked before every request and
disallowed paths (often `/cart` on Shopify stores) are skipped and logged. 2–3 s between requests.
Every page is timestamped.

### Sites

Edit `scraper/sites.json` (name, sector, URL, link hints for category/product discovery, cart path).

* `scraper/data/candidates.jsonl`, `classified.jsonl`, `crops/`, `chroma/`
* `scraper/report/report.html` + figures (PNG, ready for slides)
